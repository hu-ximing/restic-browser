# restic-browser v0.1 产品说明

## 文档状态

- **当前实现**：本地仓库的只读浏览闭环和默认 `rustic_core` 后端已进入当前代码。
- **已决定但尚未实现**：在大型真实仓库上完成性能门槛验收；当前 CI 配置已经覆盖三平台，
  但仍需以实际 CI 运行结果作为发布证据。
- **未来设想**：远程仓库、更多预览类型和凭据库等没有纳入 v0.1。

## 产品目标和用户场景

`restic-browser` 面向已有本地 restic 仓库、希望避免反复组合命令的用户。v0.1 提供：

> 打开本地仓库 → 输入一次密码 → 选择快照 → 浏览或搜索文件 → 预览 → 导出文件或恢复目录

典型场景是查看某次快照的内容、查找遗忘位置的文件、导出前确认文本/图片/视频画面，以及
只读取回一个文件。Windows x64 是发布优先级；产品行为同时面向 Windows、Linux 和
macOS。

## 完整操作流程

1. 用 `-r/--repository <path>` 指定本地仓库；未提供时读取 `RESTIC_REPOSITORY`。
2. 默认选择 `rustic_core` 后端。需要行为对照或处理默认后端不支持的本地路径时，显式加
   `--backend restic-cli`；应用不会自动切换后端。
3. 程序检查所选仓库后端，然后隐藏输入一次仓库密码；ffmpeg/ffprobe 仅在对应媒体预览
   时按需使用。
4. 仓库成功解锁后读取快照并进入 TUI；认证或格式验证失败时直接返回分类错误。
5. 快照按时间倒序显示。选择快照、展开目录树或进入目录时只读取当前层级，不预加载整棵
   文件树；已读取的目录会在当前快照内复用。
6. `/` 在当前快照中搜索。任务异步执行并可取消，但结果在一次操作完成后整体显示，单次
   最多返回 100,000 条。
7. 选中文件后：
   - 光标停留 300 ms 后自动读取该路径在所有快照中的版本历史；
   - 文本最多读取 2 MiB；
   - 常见图片通过终端图形协议或 Unicode half-block 显示；
   - 视频由 ffprobe 读取元数据、ffmpeg 提取指定时间点的单帧；
   - 音频和未知类型只显示可获得的元数据；
   - 超过 512 MiB 的源文件不读取内容，只显示元数据。
8. 单文件导出先写入目标同目录的随机临时文件，成功后无覆盖落盘。
9. 目录导出始终通过 restic CLI 的 `restore` 恢复到“输入父目录/原目录名”，不合并已有
   同名目录；即使浏览后端是 `rustic_core` 也不调用其 restore。
10. `q` 或 `Ctrl+C` 退出，终端状态由守卫恢复。

默认后端在首次预览或导出时会一次性建立完整内容索引；大型仓库可能在这一步出现可见等待
和资源峰值。后续文件读取复用该索引，详见
[architecture.md](architecture.md#目录与文件读取延迟)。

## v0.1 功能范围

### 当前实现

- restic 仓库格式 v1/v2 的本地仓库读取。
- `rustic_core` 默认后端；restic 0.19.x CLI 显式回退后端。
- 快照列表、懒加载目录树、逐层目录浏览、返回上级和刷新。
- 快照、目录树和文件列表保留独立滚动视口，并支持 `PgUp` / `PgDn` 分页。
- 文件类型、当前快照及当前目录的父路径链使用颜色区分。
- 当前快照中的 glob/pattern 搜索。
- 文件路径、类型、大小、修改时间等基本信息。
- 普通文件按同一路径列出整个仓库中的快照历史，并可预览或导出任一历史版本。
- 文本、常见图片和视频指定时间帧预览；其他类型降级为元数据。
- 当前活动任务取消。
- 中文、空格和 Emoji 文件名浏览、搜索、读取和导出。
- 单文件无覆盖导出、目录无合并恢复与可选脱敏诊断日志。

### 已决定但尚未实现

- 以大型真实仓库验证首次完整索引的时间、CPU 和内存门槛。
- 发布前取得 Windows、Linux、macOS CI 的成功运行记录。

## 明确的非目标

- 备份、删除快照、修复、迁移、检查健康状态或其他仓库写操作。
- 远程仓库和云端凭据配置。
- 多选导出、tar/zip 归档导出或覆盖已有目标。
- 跨快照内容差异比较、相同内容折叠或文件重命名追踪。
- PDF 页面、音频播放或连续视频播放。
- 系统 Keychain/Credential Manager 或密码持久化。
- 安装器，或捆绑 restic、ffmpeg、ffprobe。

未来可能评估远程后端、更多格式、目录缓存和系统凭据库，但这些不是当前承诺。

## 键盘交互

| 按键 | 行为 |
| --- | --- |
| `` ` `` | 将焦点切换到快照栏 |
| `Tab` | 宽屏时将焦点切换到目录树 |
| `Space` | 将焦点切换到当前目录文件列表 |
| `v` | 加载并将焦点切换到当前普通文件的版本历史 |
| `↑` / `k` | 上移选择 |
| `↓` / `j` | 下移选择 |
| `PgUp` / `PgDn` | 先移动到当前视图顶部/底部；已在边缘时翻到上一页/下一页并保持边缘位置 |
| `Home` / `End` | 移动到当前栏的第一项 / 最后一项 |
| `Enter` | 确认快照、打开树中目录或进入文件列表中的目录；选中文件时打开预览 |
| `Backspace` | 文件列表返回上级目录；目录树折叠当前节点或选择父节点 |
| `←` | 文件列表返回上级目录，已在根目录时切换到快照栏；目录树折叠当前节点或选择父节点；版本历史返回文件列表 |
| `→` | 目录树按需展开；文件列表进入目录或打开普通文件的版本历史；快照栏确认游标快照并切换到对应文件列表 |
| `/` | 输入当前快照的搜索 pattern；结果出现时目录树保持不变，打开结果时才展开到对应位置 |
| `p` | 预览当前文件，或版本历史中高亮的版本 |
| `e` | 文件或高亮历史版本：输入导出目录；目录：输入恢复目标父目录；原名称保持不变 |
| `r` | 刷新当前目录 |
| `Esc` | 取消当前活动任务或关闭输入 |
| `q` | 取消当前任务并退出 |
| `Ctrl+C` | 在任意输入模式下退出 |

搜索和导出输入框支持字符输入、`Backspace`、`Enter` 和 `Esc`。目标目录默认为当前工作
目录 `.`，支持相对路径、绝对路径和 `~` 主目录展开；父目录必须已存在。文件不会覆盖
同名文件，目录不会合并同名目录。按键释放事件被忽略，标准的按住重复事件保留。

目录树底部显示当前选中目录的完整路径。切换目录时会清除旧目录的预览；预览元数据的
标签采用统一宽度，使所有值从同一列开始。

终端至少为 `120 × 30` 时使用三栏布局，右栏按 40%/60% 显示版本历史和预览。更小的
终端隐藏目录树，并在下方区域通过 `v` 和 `p` 切换版本历史/预览；此时 `Tab` 不执行操作。

只有当前焦点面板显示选择框，框内文字统一为黑色。目录树、文件列表和快照栏均不使用
`>`。文件列表所属的已生效快照使用普通白色，其他快照淡化显示。

目录树使用 `│`、`├──` 和 `└──` 表示父子及同级关系。当前目录链会给目录名、直接连到
该目录的 `├──` / `└──` 线段，以及通向下一层当前目录的祖先竖线着色；无关分支的延伸
线保持默认颜色。在目录树中按 `Enter` 后，如果展开的子目录未完全进入当前视图，视图会
向上移动，直到最后一个子目录可见，或所选目录已经到达视图第一行。

## 验收标准

| 标准 | 当前证据 |
| --- | --- |
| 一次运行只输入一次密码 | 两个后端均复用会话中的认证状态 |
| 快照、逐层目录和搜索可用 | 单元测试及真实仓库双后端集成测试 |
| 文本、图片和视频帧预览可用 | restic 0.19.1 真实仓库集成测试 |
| 单文件导出字节一致且不覆盖 | SHA-256 对照和无覆盖落盘实现 |
| 目录恢复层级一致且不合并 | CLI restore 集成测试和目标目录独占创建 |
| 中文、空格和 Emoji 路径可读取 | v1/v2 真实仓库测试；显示仍依赖终端字体 |
| 产品操作不修改仓库 | 只读接口/CLI 白名单；集成测试比较操作前后仓库内容 |
| 密码不进入参数、配置或日志 | `rustic_core` 解锁后清零输入；CLI 仅用子进程环境；日志脱敏 |
| 取消不留下输出半成品 | 取消测试、临时文件作用域和部分恢复目录清理 |
| Windows、Linux、macOS 可构建测试 | CI 矩阵已配置；发布前需确认实际运行成功 |
| 大型仓库资源可接受 | 尚需真实仓库性能验收 |
