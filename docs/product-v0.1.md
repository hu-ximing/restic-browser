# restic-browser v0.1 产品说明

## 文档状态

- **当前实现**：本文所列 v0.1 浏览闭环已经存在于当前代码。
- **已决定但尚未实现**：仓库读取后端计划评估并迁移到 `rustic_core`，见
  [rustic-core-migration.md](rustic-core-migration.md)。
- **未来设想**：不属于 v0.1，也没有排期。

## 产品目标和用户场景

`restic-browser` 是一个只读 TUI，面向已经拥有本地 restic 仓库、但不希望为日常查找和
取回文件反复组合命令的用户。v0.1 的目标闭环是：

> 打开本地仓库 → 输入一次密码 → 选择快照 → 浏览或搜索文件 → 预览内容 → 导出单个文件

典型场景包括：

- 查看某次快照中保存了哪些目录和文件。
- 按 restic pattern 在选定快照中查找文件。
- 导出前确认文本、图片或视频某个时间点的画面。
- 将一个文件安全地取回到本地，不改变仓库。

Windows x64 是当前发布优先级；应用代码和交互原则同时面向 Windows、Linux 和 macOS。

## 完整操作流程

### 当前实现

1. 使用 `-r/--repository <path>` 指定本地仓库；未提供时读取
   `RESTIC_REPOSITORY`。
2. 程序检查 restic 0.19.x、ffmpeg 和 ffprobe 是否可执行。可分别用
   `--restic`、`--ffmpeg` 和 `--ffprobe` 覆盖自动查找结果。
3. 程序在终端中隐藏输入仓库密码。密码在本次进程中复用。
4. 程序读取快照；认证或仓库验证失败时不会进入 TUI。
5. TUI 按时间倒序显示快照，并异步加载当前快照的根目录。
6. 用户逐层进入目录，或用 `/` 搜索当前快照。目录只在进入或刷新时查询，不预加载整棵
   文件树。
7. 选中文件后可以查看基本元数据、打开预览或导出：
   - 文本最多显示 2 MiB。
   - 图片在终端支持的图形方式或 Unicode half-block 中显示。
   - 视频使用 ffprobe 读取元数据，使用 ffmpeg 提取单帧；左右键以 5 秒为步长定位。
   - 音频和未知类型不播放；尽可能显示媒体元数据。
   - 超过 512 MiB 的源文件不生成预览。
8. 单文件导出先写到目标目录中的临时文件，成功后再无覆盖地持久化为目标名称。
9. `q` 或 `Ctrl+C` 退出；终端的 raw mode、备用屏幕和光标由守卫恢复。

当前搜索、目录列表和快照列表会在对应命令完成后一次性显示，并非流式追加。

## v0.1 功能范围

### 当前实现

- 本地 restic 仓库，正式限定 restic 0.19.x。
- 快照列表、当前层目录浏览、返回上级和刷新。
- 当前快照内的 restic pattern 搜索。
- 文件路径、大小和修改时间等基本信息。
- 文本、常见图片和常见视频格式的预览；音频和未知类型的元数据降级。
- 视频指定时间点单帧，不做连续播放。
- 单文件导出，默认且始终拒绝覆盖。
- 当前活动任务的取消。
- 中文、空格和 Emoji 文件名的 JSON 解析、领域数据链路和集成测试。
- 可选的脱敏诊断日志。

### 已决定但尚未实现

- 用 `rustic_core` 建立一次解锁、会话内复用的读取后端。
- 在迁移验证通过前保留当前 restic CLI 后端作为对照和回退。

## 明确的非目标

### v0.1 非目标

- 创建备份、删除快照、修复、迁移、解锁、检查健康状态或其他仓库管理操作。
- 远程仓库配置和云端凭据管理。
- 目录导出、多选导出或覆盖已有目标。
- 跨快照版本比较。
- PDF 页面预览、音频播放或连续视频播放。
- 系统 Keychain/Credential Manager 集成或持久化密码。
- 安装器或捆绑 restic、ffmpeg、ffprobe。

### 未来设想

远程后端、跨快照比较、更多预览格式和系统凭据库只能在只读边界、资源上限和跨平台行为
明确后另行设计，不属于当前迁移承诺。

## 键盘交互

### 普通模式

| 按键 | 行为 |
| --- | --- |
| `Tab` | 在快照列表和文件列表之间切换焦点 |
| `↑` / `k` | 上移选择 |
| `↓` / `j` | 下移选择 |
| `Enter` | 选择快照、进入目录；选中文件时打开预览 |
| `Backspace` | 返回上级目录 |
| `/` | 打开当前快照的搜索输入框 |
| `p` | 预览当前文件 |
| `←` / `→` | 已打开视频预览时后退/前进 5 秒并重新生成帧 |
| `e` | 打开单文件导出目标输入框，默认值为当前文件名 |
| `r` | 刷新当前目录 |
| `Esc` | 取消当前活动任务 |
| `q` | 取消当前任务并退出 |
| `Ctrl+C` | 在任意输入模式下退出 |

### 搜索和导出输入框

可输入字符，`Backspace` 删除末尾字符，`Enter` 提交，`Esc` 放弃输入。按键释放事件会被
忽略，按住按键产生的标准重复事件会保留。

## 验收标准

以下是 v0.1 的产品验收目标；“已有证据”描述当前代码和测试覆盖，不代表尚未运行的环境
已经验收。

| 标准 | 当前状态与证据 |
| --- | --- |
| 一次运行只输入一次密码 | 已实现；后续 restic 子进程复用内存中的密码 |
| 浏览快照和逐层目录 | 已实现；快照倒序，目录按需查询 |
| 搜索选定快照 | 已实现；使用 restic pattern |
| 预览文本、图片和视频指定时间帧 | 已实现；真实仓库集成测试覆盖三类文件 |
| 未支持类型仍可查看基本信息并导出 | 已实现 |
| 单文件导出与 `restic dump` 字节一致 | 集成测试以 SHA-256 验证 |
| 中文、空格和 Emoji 文件名可读取 | 集成测试覆盖；最终显示仍依赖终端字体和 Unicode 宽度处理 |
| 目标存在时不覆盖，失败不留下目标临时文件 | 使用同目录临时文件和无覆盖持久化实现 |
| 不执行修改仓库的产品命令 | 命令白名单单元测试只允许 `snapshots`、`ls`、`find`、`dump` |
| 密码不进入配置、日志或命令参数 | 密码仅存于进程内存，并只传给 restic 子进程环境 |
| 取消和退出不遗留子进程，终端可恢复 | 已实现取消和 RAII 恢复；仍需补充取消竞争的端到端压力验收 |
| Windows x64 发布可用 | 当前 CI 在 Windows 构建 release artifact |
| Linux/macOS 行为可移植 | Linux CI 编译并测试；macOS 尚未进入 CI，需发布前人工或 CI 验证 |
